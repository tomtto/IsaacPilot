# Архив — карта файлов и хронология

Эта папка — не мусор и не дубли. Это последовательные слепки истории проекта, каждый описывает свою фазу. Если нужен **практический** результат (что чинить, как ставить) — смотри `TROUBLESHOOTING.md` и `INSTALL.md` в корне репозитория, они уже отфильтрованы из этих файлов. Сюда стоит заглядывать, только если нужна **сырая** история конкретного решения — с датами, логами, отвергнутыми гипотезами.

## Порядок фаз проекта

### 1. `context.md` — Фаза 1: установка Isaac Sim + собственный контроллер (ЗАБРОШЕНО)
Самый ранний файл. Установка Isaac Sim с нуля, первый дрон (Bitcraze Crazyflie `cf2x`), приложение силы через `omni.physx` API, и дальше — **60+ итераций** попытки написать свой геометрический контроллер стабилизации (без ArduPilot вообще). Контроллер так и не стабилизировался; проект сознательно перешёл на готовый автопилот (Фаза 2). Ценность файла сегодня — не сам контроллер (он не используется), а въедливая отладка низкоуровневой физики PhysX/USD (масса, инерция, Scale, коллизии, системы координат), которая пригодилась и в финальной версии моста.

### 2. `context_ardu.md` — Фаза 2 (ранняя): первый мост к ArduPilot SITL
Первая рабочая версия подключения ArduPilot SITL к Isaac Sim — через отдельные файлы `wsl_bridge.py` (мост в WSL) и `arm_takeoff.py` (минимальный MAVLink-клиент), с ручным запуском в 2-3 терминалах. Здесь разобран сам протокол ArduPilot JSON SITL (формат пакетов, magic number, обязательные поля JSON, RC-каналы) — это тот слой, который не изменился и в финальной архитектуре. Архитектура запуска (терминалы, `wsl_bridge.py`) с тех пор заменена на единый `isaac_bridge.py` + notebook'и (см. следующий пункт).

### 3. `isaac_ardupilot_bridge_memory.md` — Фаза 2 (финал): рабочая архитектура
Снимок финальной, работающей конфигурации: физика 240Hz, Iris-репспек, конверсия FLU→FRD («Фикс-12»), lockstep UDP, флоу «2 notebooks, ноль терминалов» через `isaac_bridge.py`. Это состояние на момент переноса проекта на GitHub (2026-07-11/12). Копия того же файла, что в активной памяти агента (`isaac_project_status_*.md` в памяти — короткая выжимка, этот файл — полная версия).

### Код-артефакты Фазы 2 (ранней), больше не используются
- `wsl_bridge.py` — WSL-мост первой версии (терминальный флоу)
- `arm_takeoff.py` — минимальный MAVLink ARM+takeoff клиент
- `test_motors.py` — диагностика PWM/RC через ручной override каналов

Все три заменены на `isaac_bridge.py` (мост) + `notebooks/flight_missions.ipynb` (миссии) в корне репозитория. Оставлены здесь как историческая справка и рабочий пример «как устроен протокол на самом низком уровне», если понадобится отладка с нуля.
