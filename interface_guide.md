## Основные панели

| Панель | Где находится | Что делает |
|---|---|---|
| **Viewport** | Центр экрана | Главное окно 3D-сцены — здесь видишь и крутишь объекты, как в UE5 |
| **Stage** | Справа сверху | Дерево всех объектов сцены (как Outliner / World Outliner в UE5) |
| **Property** | Справа снизу | Свойства выбранного объекта — позиция, поворот, материалы (как Details panel в UE5) |
| **Content / Content Browser** | Снизу слева | Библиотека готовых ассетов — роботы, окружения, материалы (как Content Browser в UE5) |
| **Console** | Снизу (рядом с Content) | Лог сообщений и ошибок системы |
| **Toolbar** | Слева, вертикальная полоса иконок | Инструменты выделения, перемещения, вращения, масштаба, запуск симуляции |
| **Menu Bar** | Самая верхняя строка | File, Edit, Create, Window, Tools, Utilities — создание объектов, настройки, доступ к окнам |

Все панели можно перетаскивать, отстыковывать в отдельные окна (tear off) и перестраивать под себя — так же как в UE5.

## Горячие клавиши

### Манипуляция объектами (как в UE5!)
| Клавиша | Действие |
|---|---|
| `W` | Инструмент перемещения (Move) |
| `E` | Инструмент вращения (Rotate) |
| `R` | Инструмент масштабирования (Scale) |
| `Esc` | Снять выделение |

### Навигация камерой во вьюпорте
Зажми **правую кнопку мыши (ПКМ)**, и пока держишь — двигайся клавишами:

| Клавиша | Действие |
|---|---|
| `W` / `↑` | Вперёд |
| `S` / `↓` | Назад |
| `A` / `←` | Влево |
| `D` / `→` | Вправо |
| `Q` / `Page Up` | Вверх |
| `E` / `Page Down` | Вниз |

> Зажми `Shift` во время движения — ускорение x2. Зажми `Ctrl` — замедление в 2 раза.

### Управление камерой (без зажатой W/A/S/D)
| Действие | Как сделать |
|---|---|
| Приблизить/отдалить | Колесо мыши |
| Вращение вокруг центра сцены | `Alt` + ЛКМ |
| Панорама (сдвиг вида) | Средняя кнопка мыши (колесо) |
| Свободный поворот камеры | Удержание ПКМ |
| Сфокусироваться на объекте | `F` (выдели объект и нажми) |

### Выделение объектов
| Клавиша | Действие |
|---|---|
| ЛКМ | Выбрать объект |
| `Ctrl + A` | Выделить всё |
| `Ctrl + I` | Инвертировать выделение |

### Файлы
| Клавиша | Действие |
|---|---|
| `Ctrl + S` | Сохранить |
| `Ctrl + O` | Открыть файл |

### Работа с объектами
| Клавиша | Действие |
|---|---|
| `Delete` | Удалить выбранный объект |
| `Ctrl + D` | Дублировать |
| `Ctrl + G` | Сгруппировать в контейнер |
| `Ctrl + Shift + I` | Создать инстанс (копию-ссылку) |
| `H` | Показать/скрыть объект |

### Интерфейс
| Клавиша | Действие |
|---|---|
| `Shift + H` | Показать/скрыть сетку и инфо-панель |
| `F7` | Скрыть/показать весь UI (только вьюпорт) |
| `F10` | Скриншот |
| `F11` | Полноэкранный режим |

### Симуляция
| Клавиша | Действие |
|---|---|
| `Пробел` | Запустить/поставить на паузу симуляцию (как Play в UE5) |

Чтобы добавить первый объект в сцену:
1. Открой **Content** (снизу слева) → папка `Isaac Sim` → `Robots` или `Samples`
2. Перетащи нужный ассет (.usd файл) во **Viewport**
3. Объект появится в **Stage** справа, можно выделить и двигать клавишей `W`

## Манипуляция объектами в сцене

### Как выбрать и подвинуть объект
1. Кликни на объект во **Viewport** или на его строку в **Stage** (справа) — он подсветится оранжевым
2. Нажми `W` — появится цветной гизмо (виджет-стрелки): **красная = X, зелёная = Y, синяя = Z**
3. Тяни за стрелку нужного цвета мышкой — объект сдвинется только по этой оси
4. `E` — то же самое, но для вращения (кольца вместо стрелок)
5. `R` — масштабирование (кубики на осях)

### Точный ввод координат
Вместо мышки можно вписать число напрямую в панели **Property** (справа снизу) → блок **Transform**:
- `Translate` — позиция X/Y/Z
- `Rotate` — поворот по осям
- `Scale` — масштаб

Кликни на число и впиши своё — полезно когда нужна точность (например, поставить объект ровно на `Z: 0`).

### Почему гизмо "завис" наверху после падения дрона
Это нормальное поведение, не баг:

- Когда симуляция **запущена (Play)** — то, что ты видишь во вьюпорте, это быстрый физический просчёт (через слой Fabric), который отрисовывается в реальном времени
- Но панель **Property** и позиция гизмо показывают **изначально записанную (authored) трансформацию** в USD-сцене — она не обновляется на лету ради производительности
- Поэтому визуально дрон упал, а гизмо/цифры в Property остались там, где дрон был **до старта** симуляции

**Важно:** если нажмёшь **Stop** — дрон вернётся в исходную позицию (туда, где стоял до Play), а не останется лежать на полу. Stop откатывает сцену назад, а не сохраняет результат физики.

Если хочешь зафиксировать "упавшее" положение как новое постоянное — нужно вручную переписать Translate/Rotate в Property после остановки, либо использовать специальные инструменты записи симуляции (это уже продвинутая тема, обсудим отдельно когда понадобится).

## Создание и сохранение проекта

В Isaac Sim (как и во всём Omniverse) нет привычного по UE5 понятия "проект" с единым файлом `.uproject`. Вместо этого:

- Вся сцена — это один файл **`.usd`** (или `.usda`/`.usdc`) — он называется **Stage**
- Этот файл может **ссылаться** на другие `.usd` файлы (роботов, окружения) — как у тебя сейчас `simple_room` и `cf2x` подключены в общую сцену
- Папка с твоими `.usd` файлами и есть твой "проект" — организуешь её сам как обычные файлы

### Сохранить текущую сцену
1. `Ctrl + S` — быстрое сохранение
2. Или меню **File → Save As** — выбрать куда и под каким именем

**Рекомендация:** создай папку для сцен внутри проекта, например:
```
C:\VSCODE\ISAAC\scenes\
```
И сохраняй туда — например `my_first_scene.usd`. Так все твои сцены будут отдельно от системных файлов среды (`isaac_env`).

### Создать новую пустую сцену
**File → New** — откроется чистый Stage без объектов, готовый для нового проекта.

### Открыть сохранённую сцену
**File → Open** (или `Ctrl + O`) — выбираешь свой `.usd` файл из папки `scenes`.
